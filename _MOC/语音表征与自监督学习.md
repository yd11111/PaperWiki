## 核心概念
- [[Self-Supervised Speech Representation]] — 自监督语音表征学习, 从无标注语音学习通用特征
- [[Speech Tokenizer]] — 语音离散化, SSL 特征是主要离散化对象
- [[Semantic vs Acoustic Tokens]] — 语义与声学 token 的区分, SSL 模型提供 semantic token
- [[Masked Generative Modeling]] — 掩码预测训练范式 (HuBERT/BEATs)
- [[Gumbel-Softmax]] — 可微离散采样 (wav2vec 2.0/w2v-BERT)

## 代表模型
- [[wav2vec 2.0]] — Meta, 2020, 对比学习 + Gumbel-Softmax 量化
- [[HuBERT]] — Meta, 2021, offline k-means targets + masked prediction
- [[WavLM]] — Microsoft, 2022, denoising + speaker preservation pretraining
- [[w2v-BERT]] — Google, 2022, contrastive + masked prediction 联合
- [[Whisper]] — OpenAI, 2022, 680K hrs 弱监督多任务 ASR

```
wav2vec 2.0 (2020, 对比学习 + Gumbel-Softmax)
  → HuBERT (2021, offline clustering + masked prediction)
  → WavLM (2022, denoising + speaker preservation)
  → w2v-BERT (2022, contrastive + MLM 联合)
  → w2v-BERT 2.0 (2023, 580M/4.5M hrs/143 languages)
  → XEUS (2024, E-Branchformer, 1M hrs/4057 languages)
  → BEATs (2023, iterative self-distilled tokenizer, audio understanding)
  → Whisper (2022, 弱监督多任务, 680K hrs)
  → Seamless (2023, SSL encoder + 端到端 S2ST)

评估:
  → Dynamic-SUPERB (2024, 180 tasks, 17 domains)
  → SSL Suprasegmental Analysis (2024, layer-wise probing)
```
