## 核心概念
- [[Self-SupervisedSpeechRepresentation]] — 自监督语音表征学习, 从无标注语音学习通用特征
- [[SpeechTokenizer]] — 语音离散化, SSL 特征是主要离散化对象
- [[SemanticvsAcousticTokens]] — 语义与声学 token 的区分, SSL 模型提供 semantic token
- [[MaskedGenerativeModeling]] — 掩码预测训练范式 (HuBERT/BEATs)
- [[Gumbel-Softmax]] — 可微离散采样 (wav2vec 2.0/w2v-BERT)

- [[wav2vec2.0]] — Meta, 2020, 对比学习 + Gumbel-Softmax 量化

- [[WavLM]] — Microsoft, 2022, denoising + speaker preservation pretraining

