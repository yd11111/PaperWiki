## 核心概念
- [[ResidualVectorQuantization]] — 多层级向量量化，现代 neural audio codec 的核心量化模块
- [[FiniteScalarQuantization]] — 无码本的固定网格量化，天然避免 codebook collapse
- [[CodebookCollapse]] — VQ/RVQ 训练中码本利用率低的常见病理现象
- [[QuantizerDropout]] — RVQ 训练技巧，实现单模型可变比特率推理
- [[SpeechTokenizer]] — 将连续语音转换为离散 token 序列的模块（含声学 tokenizer）
- [[SnakeActivation]] — 周期性激活函数，为 codec decoder 引入周期 inductive bias
- [[Multi-scaleSTFTDiscriminator]] — 频域判别器，多尺度 + 多频带建模高频与相位

## 代表模型
- [[SoundStream]] — Google, 2021, 端到端 neural audio codec (作者 claim 首个), encoder-decoder + RVQ 范式
- [[EnCodec]] — Meta AI, 2022, 改进 RVQ 训练（EMA codebook），支持 1.5-24 kbps
- [[BigVGAN]] — NVIDIA, 2023, 通用神经声码器，Snake activation + 大规模训练

## 演进脉络

```
VQ-VAE (2017, discrete latent + STE)
  → SoundStream (2021, RVQ + quantizer dropout)
  → EnCodec (2022, EMA codebook)
  → DAC (2023, factorized codes + L2-norm, 99% utilization)
  → RepCodec (2024, representation codec for semantic tokens)
  → SNAC (2024, Multi-Scale RVQ, 多尺度量化)
  → FSQ (2024, 去码本化) → FSQ + 监督多任务 (CosyVoice 3, 2025)
  → NAC Token Language Analysis (2025, token 统计分析, 3-gram 最像自然语言)
  → FlowDec (2025, 非对抗 codec + flow postfilter, 去 GAN 化)
  → FlexiCodec (2026, 动态帧率 <10Hz, ASR 引导 frame merging)
  → StableToken (2026, Voting-LFQ, 多分支投票量化)
  → SiTok (2026, diffusion autoencoder + CTC semantic regularization)
  → VARSTok (2025, variable-frame-rate, temporal-aware DPC + implicit duration coding)
```
