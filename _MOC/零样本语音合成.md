## 核心概念
- [[Speech Tokenizer]] — 将连续语音转为离散 token 的模块，LLM-based TTS 的关键组件
- [[Codec Language Model]] — 以 codec tokens 为目标的语言模型，VALL-E 开创的零样本 TTS 核心范式
- [[LLM-based TTS]] — 用大语言模型架构建模语音 token 序列的 TTS 方法
- [[Conditional Flow Matching]] — 基于 ODE 的生成方法，用于 token-to-mel 声学渲染
- [[Residual Vector Quantization]] — 多层级残差量化，speech codec 的标准离散化方法
- [[Variational Autoencoder for TTS]] — VAE 在 TTS 中的应用，VITS 等端到端模型的核心组件
- [[Non-autoregressive TTS]] — 非自回归 TTS 范式，MaskGCT/NaturalSpeech 系列的生成策略
- [[Duration Predictor]] — 预测音素时长的模块，非自回归 TTS 的关键组件
- [[Differentiable Reward Optimization]] — Token-level 可微 reward 优化，TTS post-training 方法
- [[Speech Factorization]] — 将语音解耦为 timbre/content/prosody，支撑 zero-shot voice conversion
- [[Masked Generative Modeling]] — Mask-and-predict 范式的非自回归生成方法
- [[Gumbel-Softmax]] — 使离散 token 采样可微分的重参数化技巧
- [[Gradient Reversal Layer]] — 对抗训练实现属性解耦（如情感-音色正交化）

## 代表模型
- [[VITS]] — Kakao, 2021, 端到端 VAE+GAN+normalizing flow TTS，零样本 TTS 基础架构
- [[NaturalSpeech 2]] — Microsoft, 2024, latent diffusion + RVQ codec，非自回归零样本 TTS
- [[NaturalSpeech 3]] — Microsoft, 2024, factorized codec + discrete diffusion，属性解耦 TTS
- [[HierSpeech++]] — 2023, hierarchical speech factorization，多层级零样本 TTS/VC
- [[MELLE]] — Microsoft, 2024, 连续值 mel spectrogram AR LM，无离散化 TTS
- [[Make-A-Voice]] — 2024, codec LM + prosody 分解 + 音色克隆
- [[CosyVoice 3]] — Alibaba, 2025, 1.5B 参数，9 语种 + 18 方言，DiffRO post-training
- [[CosyVoice 2]] — Alibaba, 2024, 可扩展流式零样本 TTS，双向流式方案
- [[MinMo]] — Alibaba, 2025, 多模态语音 LLM，为 CosyVoice 3 提供 tokenizer backbone
- [[BigVGAN]] — NVIDIA, 2023, 通用神经声码器，zero-shot TTS pipeline 终端
