## 核心概念
- [[Speech Tokenizer]] — 将连续语音转为离散 token 的模块，LLM-based TTS 的关键组件
- [[Codec Language Model]] — 以 codec tokens 为目标的语言模型，VALL-E 开创的零样本 TTS 核心范式
- [[LLM-based TTS]] — 用大语言模型架构建模语音 token 序列的 TTS 方法
- [[Conditional Flow Matching]] — 基于 ODE 的生成方法，用于 token-to-mel 声学渲染
- [[Residual Vector Quantization]] — 多层级残差量化，speech codec 的标准离散化方法
- [[Variational Autoencoder for TTS]] — VAE 在 TTS 中的应用，VITS 等端到端模型的核心组件
- [[Non-autoregressive TTS]] — 非自回归 TTS 范式，MaskGCT/NaturalSpeech 系列的生成策略
- [[Duration Predictor]] — 预测音素时长的模块，非自回归 TTS 的关键组件
- [[Differentiable Reward Optimization]] — Token-level 可微 reward 优化，TTS post-training 方法
- [[Speech Factorization]] — 将语音解耦为 timbre/content/prosody，支撑 zero-shot voice conversion
- [[Masked Generative Modeling]] — Mask-and-predict 范式的非自回归生成方法
- [[Gumbel-Softmax]] — 使离散 token 采样可微分的重参数化技巧
- [[Gradient Reversal Layer]] — 对抗训练实现属性解耦（如情感-音色正交化）

## 代表模型
- [[VITS]] — Kakao, 2021, 端到端 VAE+GAN+normalizing flow TTS，零样本 TTS 基础架构
- [[NaturalSpeech 2]] — Microsoft, 2024, latent diffusion + RVQ codec，非自回归零样本 TTS
- [[NaturalSpeech 3]] — Microsoft, 2024, factorized codec + discrete diffusion，属性解耦 TTS
- [[HierSpeech++]] — 2023, hierarchical speech factorization，多层级零样本 TTS/VC
- [[MELLE]] — Microsoft, 2024, 连续值 mel spectrogram AR LM，无离散化 TTS
- [[Make-A-Voice]] — 2024, codec LM + prosody 分解 + 音色克隆
- [[CosyVoice 3]] — Alibaba, 2025, 1.5B 参数，9 语种 + 18 方言，DiffRO post-training
- [[CosyVoice 2]] — Alibaba, 2024, 可扩展流式零样本 TTS，双向流式方案
- [[MinMo]] — Alibaba, 2025, 多模态语音 LLM，为 CosyVoice 3 提供 tokenizer backbone
- [[BigVGAN]] — NVIDIA, 2023, 通用神经声码器，zero-shot TTS pipeline 终端

## 演进脉络

```
端到端 TTS 基础:
  VITS (2021, VAE+GAN+flow, 首个端到端高质量 TTS)
    → YourTTS (2022, VITS-based 多语言零样本 TTS/VC)

LLM/Codec Token 路线 (自回归):
  AudioLM (2022, semantic+acoustic 层级建模, 无文本语音续写)
    → SPEAR-TTS (2023, AudioLM→TTS, 15min 平行数据, 回译+预训练)
    → SoundStorm (2023, masked generative 并行解码 acoustic tokens, 与 AudioLM 互补)
  VALL-E (2023, LLM + codec tokens, zero-shot 开端)
    → SC VALL-E (2024, style network 嵌入 NAR block)
    → Make-A-Voice (2024, codec LM + prosody 分解 + 音色克隆)
    → TextrolSpeech (2024, 文本风格控制 + Salle codec LM)
  Tortoise TTS (2023, AR+DDPM 两阶段, CLVP re-ranking 先驱)
  BASE TTS (2024, 10B 参数 LLM, 100K hrs scaling)
  UniAudio (2024, 统一音频生成 LLM, 多任务)
  Seed-TTS (2024, AR + token diffusion, 人类水平, RL post-training)
  FireRedTTS (2024, LLM+CFM 零样本 TTS)
    → FireRedTTS 2 (2025, 流式版, 自适应延迟)
  Fish-Speech (2025, 开源 LLM-based, grouped FSQ tokens)
    → Fish Audio S2 (2026, Qwen3-4B backbone, RVQ + semantic distillation, GRPO multi-reward RL)
  GLM-TTS (2025, GLM-4-Voice 组件, token-level CFM)
  VoXtream (2025, full-stream 全 AR, incremental phoneme encoding, FPL 102ms)
  Voxtral TTS (2026, Mistral, hybrid AR semantic + FM acoustic, VQ+FSQ codec, 9 语言 zero-shot)

连续值 AR 路线:
  MELLE (2024, 连续值 mel spectrogram AR LM, 无离散化)
  LatentLM (2024, next-token diffusion + sigma-VAE 统一框架)
    → VibeVoice (2025, 90min 多说话人对话, industrial-scale)
    → FELLE (2025, token-wise coarse-to-fine flow matching)
  CLEAR (2025, rectified flow head + enhanced VAE, 单阶段流式)

非自回归/Diffusion 路线:
  NaturalSpeech 2 (2024, latent diffusion + RVQ codec)
    → NaturalSpeech 3 (2024, factorized codec + discrete diffusion, 属性解耦)
  MaskGCT (2024, 完全非自回归 masked generation)
  Chatterbox-Flash (2026, AR→block-diffusion 微调, PMI scoring, 原生流式)

语音分解/克隆路线:
  Mega-TTS (2023, 四维分解 + P-LLM, inductive bias 路线)
    → Mega-TTS 2 (2024, diffusion prosody + codec timbre)
  HierSpeech++ (2023, hierarchical factorization + super-resolution)
  Seed-VC (2024, zero-shot VC, timbre shifter + DiT + flow matching)
    → USM-VC (2025, universal semantic dictionary + CFR)

Post-training / 可控生成:
  CosyVoice 系列 (2024-2025, FSQ tokenizer + CFM + DiffRO)
    → IndexTTS2 (2025, duration control + emotion disentanglement)
    → NVSpeech (2025, 副语言发声 pipeline, 18 类 PV 标注)
  FlexiVoice (2025, progressive post-training DPO→GRPO)
  MambaVoiceCloning (2025, SSM-only diffusion conditioning, 21M params)

音乐/歌声生成:
  SongGen (2024, 单阶段 AR text-to-song, mixed/dual-track patterns)
```
