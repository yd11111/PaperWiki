### 1. VIB-AVSR: Variational Information Bottleneck for Noise-Robust LLM-Based Audio-Visual Speech Recognition

- **作者**: Piyush, Navlika, Umberto, Stavros, Maja
- **机构**: Imperial College London, UK;NatWest AI Research, UK
- **链接**: [arXiv](https://arxiv.org/abs/2606.29632) | [PDF](https://arxiv.org/pdf/2606.29632)
- **来源**: 📄 arXiv 关键词检索
![](https://arxiv.org/html/2606.29632v1/x1.png)
- **核心方法**: 输入是含噪的音频流 + 唇动视频流,输出是转写文本。基线是 Llama-AVSR(音视频编码器 + 线性投影 + LLM backbone)。本文在 LLM backbone 的特定位置插入 [[变分信息瓶颈]](Variational Information Bottleneck, VIB)层,对表征做正则,抑制含噪音频带来的表征漂移。卖点是不改架构、不加训练数据,纯靠正则层提升多种 SNR / 噪声类型下的鲁棒性。
- **对比方法/Baselines**: [[Llama-AVSR]](直接基线)、[[HuBERT]](音频编码器)、[[LoRA]](微调方式)
- **借鉴意义**: 对做噪声鲁棒 ASR / 音视频融合的人有一定参考——"在 LLM 内部插正则层而非改架构"是个轻量思路。对 TTS 方向基本无直接用途。
- **锐评**: 贡献很小:本质就是给现成模型加了个正则模块,消融做得规矩(插入位置 / β / α 三张表)但全在 babble 噪声下测,泛化性没交代。claim 与证据基本匹配,不吹牛,但也谈不上惊喜。方向对、增量足够小。🫠
- **🧪 锐评依据**:
  - `Claim: 贡献是往现成 Llama-AVSR 里插 VIB 层做正则,不改架构不加数据` | `Evidence: 摘要 "integrates Variational Information Bottleneck layers at targeted positions within the LLM backbone ... without requiring architectural modifications or additional training data"` | `Confidence: 高`

### 2. VeRe-Flow: Guiding Flow Matching toward Clean Speech via Velocity Contrastive Regularization and Representation Alignment for Noise-Robust Bandwidth Expansion

- **作者**: Sujin, Sangyoon, Ji Sub, Hoirin
- **机构**: MAGO, South Korea;KAIST, South Korea
- **链接**: [arXiv](https://arxiv.org/abs/2606.29450) | [PDF](https://arxiv.org/pdf/2606.29450)
- **来源**: 📄 arXiv 关键词检索
![](https://arxiv.org/html/2606.29450v1/figures/architecture.jpg)
- **核心方法**: 输入含噪的低分辨率 mel 谱,输出高保真宽带语音(噪声鲁棒带宽扩展 NR-BWE)。核心是给 [[Flow Matching]] 加两层 clean 监督:速度层用 [[速度对比正则]](Velocity Contrastive Regularization),把预测速度拉向 clean 轨迹、推离 noisy 轨迹;表征层做 representation alignment,把中间特征对齐到 clean 的 [[自监督学习]](SSL)表征。解决的是含噪输入下速度估计歧义的问题。
- **对比方法/Baselines**: [[Flow Matching]](CFM 基础)、[[XEUS]](SSL 特征)、生成式与判别式 NR-BWE baseline
- **借鉴意义**: 对 TTS / 语音生成的人有迁移价值——"用 clean 轨迹做对比正则引导 flow 的速度场"是可复用的技巧,不限于带宽扩展。对 codec / 生成式增强方向也有参考。
- **锐评**: 方法设计有想法,不是简单堆模块;baseline 和消融(SSL 特征选择、ODE solver/NFE、组件消融)都齐。但要注意 claim 分寸:LSD 和 DNSMOS OVRL 是全场最好,MOS 只是"生成式 baseline 中最高"而非全场最高,说明判别式方法在保真度上仍有一席之地。诚实、扎实的工程贡献。👀
- **🧪 锐评依据**:
  - `Claim: 核心是速度对比正则 + 表征对齐两层 clean 监督引导 flow matching` | `Evidence: method_summary "Velocity Contrastive Regularization aligns v_θ with the clean trajectory and repels it from the noisy trajectories ... Representation Alignment aligns intermediate representations with clean SSL embeddings"` | `Confidence: 高`
  - `Claim: MOS 只是生成式 baseline 中最高,非全场最高` | `Evidence: 摘要 "the highest MOS among generative baselines"(而 LSD/DNSMOS 才是 "among all baselines")` | `Confidence: 高`
  - `Claim: 有充分 baseline 对比与多项消融` | `Evidence: section_headers "Baselines","Baseline Comparisons","Ablation on Choice of SSL Features","Ablation on Model Components"` | `Confidence: 高`

### 3. Preference-ASR: A Preference-Aware Test Set for Benchmarking ASR in the Era of Speech LLMs

- **作者**: Nithin Rao, Sasha, Nikolay, Piotr, Desh, Jagadeesh, Boris
- **机构**: NVIDIA, USA
- **链接**: [arXiv](https://arxiv.org/abs/2606.29534) | [PDF](https://arxiv.org/pdf/2606.29534)
- **来源**: 📄 arXiv 关键词检索
- **核心方法**: 这是一篇 benchmark / 测试集论文,不是新模型。针对当前 ASR test set 对数字、口头语、实体、大小写约定不一致、而标准 normalizer 又抹掉了用户在意的格式差异这一痛点,提出 PreferenceASR:考察 ASR 能否遵循自然语言的格式偏好指令,分 normalization / entities / disfluencies / case 四类。数据由七个开源语料经两阶段 LLM 辅助 + 人工校验构建,配套一个"偏好感知 normalizer"(选择性跳过与当前指令匹配的归一化步骤)。

- **借鉴意义**: 对做 Speech LLM / 指令可控 ASR 评测的人很有用——揭示了传统 WER 掩盖的"格式偏好遵循"能力差异,且数据集公开。对 TTS 的人间接有参考(可控生成的评测思路相通)。
- **锐评**: 选题精准,踩中了 Speech LLM 时代 ASR 评测的真空。亮点是评测面广(NVIDIA 自家 Canary-Qwen、阿里 Qwen3-Omni、微软 Phi-4-multimodal 都拉进来),而且诚实地暴露了 Phi-4 在 Earnings-22 上生成非转写文本导致 WER 爆炸的问题。作为 benchmark 论文该有的都有(四类偏好、per-dataset 分解)。唯一遗憾是只 benchmark 了四个模型,覆盖面还能更宽。👀

### 4. DTM-Codec: Dynamic Token Masking for VFR Speech Coding with Efficient Boundary Selection

- **作者**: Hoyeol, Juhan
- **机构**: Graduate School of Cultural Technology, KAIST, South Korea
- **链接**: [arXiv](https://arxiv.org/abs/2606.29480) | [PDF](https://arxiv.org/pdf/2606.29480)
- **来源**: 📄 arXiv 关键词检索
![](https://arxiv.org/html/2606.29480v1/fig.png)
- **核心方法**: 一个可变帧率(VFR)神经语音 [[Codec]]。核心是动态 token 掩码(DTM):保留选中的 encoder token,被掩位置填入可学习的 `<MASK>` embedding,并传一个二进制 keep-mask 供位置感知解码。另提出路径长度均衡(PLE)——一个线性时间的边界选择器,以极小 overhead 产生分布均匀的自适应片段。关键区别在于:在严格的等总码率(matched-total-bitrate)协议下比较,把此前 VFR 论文忽略的"传边界 side info 的开销"算进总码率。
- **对比方法/Baselines**: [[WavTokenizer]]、[[BigCodec]]、[[FlexiCodec]]、CodecSlime、[[FSQ]]/[[VQ]] 量化(固定帧率与其他 VFR 方案)
- **借鉴意义**: 对做 codec / speech tokenizer 的人有直接价值——"等总码率下才算真增益"这个方法论校准很关键,能戳穿一批 VFR 论文的虚假收益;DTM 的 mask-and-fill 思路也可复用。对 Speech LLM 的离散 token 前端间接相关。
- **锐评**: 难得的诚实之作:直接点名此前 VFR 增益"一旦把 overhead 算进总码率就变得很小甚至没有",然后用严格协议自证。消融和分析齐全(VFR 算法对比、OOD 非英语 MLS、语义评测、码本利用率)。硬伤是主观评测只用了 8 条 LibriSpeech test-clean 语料,MUSHRA 样本量偏小,主观结论说服力打折。方向扎实。👀
- **🧪 锐评依据**:
  - `Claim: 在严格等总码率协议下证明 VFR 真优于 FFR,直面此前增益被 overhead 抵消的问题` | `Evidence: 摘要 "clear gains over fixed-frame-rate baselines under a strict matched-total-bitrate protocol";"prior gains are ... often minor once these overhead bits are included in total bitrate"` | `Confidence: 高`
  - `Claim: 消融与分析覆盖广(VFR 算法对比/OOD/语义)` | `Evidence: section_headers "Ablation and Analysis","VFR Algorithm Comparison","OOD Non-English MLS Evaluation","Semantic Evaluation"` | `Confidence: 高`
  - `Claim: 主观评测样本量偏小(8 条)` | `Evidence: captions Table 3 "MUSHRA-inspired subjective evaluation on 8 utterances from LibriSpeech test-clean"` | `Confidence: 中`

### 5. Position-Aware Target Speaker Extraction for Long-Form Multi-Party Conversations: A Diarization-Free Framework for ASR

- **作者**: Yichi, Junzhe, Wangjin, Tatsuya
- **机构**: Graduate School of Informatics, Kyoto University, Japan
- **链接**: [arXiv](https://arxiv.org/abs/2606.29497) | [PDF](https://arxiv.org/pdf/2606.29497)
- **来源**: 📄 arXiv 关键词检索
![](https://arxiv.org/html/2606.29497v1/x1.png)
- **核心方法**: 面向长时多人会话 ASR。基于会议中说话人到达方向(DOA)稳定这一先验,提出 PATSE——一个多通道、位置感知的目标说话人提取前端:DOA 引导的空间编码器 + 条件器生成按说话人归属的语音流,再用简单后处理(如 VAD)推断说话人活动,从而免掉显式 [[说话人日志]](diarization)。目标是解决滑窗连续语音分离(CSS)的跨窗说话人不一致和残余串扰问题。
- **对比方法/Baselines**: [[CSS]](连续语音分离)、diarization-based pipeline、[[TSE]](目标说话人提取)、GSS / FastMNMF(空间前端)
- **借鉴意义**: 对做多人会话 ASR / 会议转写 / 前端分离的人有用。依赖麦克风阵列,离单通道 TTS / 语音生成较远,TTS 方向的人基本用不上。
- **锐评**: 思路合理——把 DOA 空间先验当锚点来保证跨窗说话人一致,免 diarization 是实用的工程简化,而且在 replayed 和真实会话上都测了、ASR 优于 CSS 和 diarization pipeline。但强约束是要多通道阵列(用到 IPD 等通道间特征),单通道场景直接失效,适用面窄。属于会议 ASR 的专用改进,不通用。👀
- **🧪 锐评依据**:
  - `Claim: 用 DOA 空间先验做多通道目标说话人提取,免显式 diarization` | `Evidence: 摘要 "uses DOA as a spatial prior to directly extract the speech of each target speaker ... without explicit diarization"` | `Confidence: 高`
  - `Claim: 在 replayed 和真实会话上都测,ASR 优于 CSS 和 diarization pipeline` | `Evidence: 摘要 "Experiments on both replayed and real conversations show consistent ASR gains outperforming CSS and diarization-based pipelines"` | `Confidence: 高`
  - `Claim: 强依赖多通道阵列,单通道不适用` | `Evidence: 摘要 "multi-channel Position-Aware Target Speaker Extraction";method_names 含 "IPD"(通道间相位差)` | `Confidence: 中`
