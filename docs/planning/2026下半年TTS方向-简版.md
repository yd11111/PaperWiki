## 差异化定位

> **"精准可控 + RL对齐 + 高效流式"** — 不拼模型规模拼控制精度，不拼通用拼可控。

- vs 通义: 他们instruct弱(CosyVoice偏zero-shot)，你做精细控制
- vs 字节: 他们关注稳定性/音质，你做可控+对齐
- vs 阶跃: 他们130B统一大模型，你做2B+精准(轻量但精)
- vs 天工: 他们全局Voice Design，你做word-level时变控制

## T0 主线

### 1. Instruct 能力拓展

**分层可控**(目前无人系统做):

```
L3: word-level 时变控制 ("第3个词加重，第7个词变柔")  ← 蓝海
L2: 段落级 context-aware (从对话历史自动推断韵律)     ← 低竞争
L1: 全局 NL instruct ("用温柔的声音说")              ← 已有baseline
```

控制方式拓展优先级:
1. 自然语言instruct (利用LLM backbone的IF能力)
2. Context-aware隐式控制 (对话场景刚需)
3. 标签体系扩展 (参考Hume AI 48维)
4. Voice Design (纯文字生成新音色)

### 2. RL for Instruct (核心创新点)

**现状诚实评估:**
- 子组件都已存在: 情感RM+RL(RRPO/EMORL-TTS)、角色扮演RL(MCLP)、指令评测(InstructTTSEval)
- **空白**: 通用多维度(语速/音高/口音/情感/停顿/强调)的instruction-following RM + RL闭环
- **风险**: 是一个明显的"下一步"，时间窗口紧(6-12个月内大概率有人做)

**建议做法:**
```
InstructTTSEval的评估维度 → 训练通用IF-Reward Model → RL/DPO优化TTS
                                    ↑
                          覆盖: acoustic param + style + role-play
                          不止情感(RRPO) 不止角色(MCLP)
```

**速度优先**: 不追求完美方案，先用LLM-as-judge(InstructTTSEval路线)做proxy reward快速验证，再训独立RM。

### 3. 架构升级

**Tokenizer**: 短期用监督语义token(通义路线)出效果 → 中期探索双流/变长token差异化

**Scaling**: 2B + 多阶段训练
- Stage 1: 低质量大规模pretrain (100万+小时)
- Stage 2: 精选高质量continue-train (1-10万小时)  
- Stage 3: RL post-training (IF-RM对齐)
- 用LLM权重初始化(Qwen3路线)，不从头训

**效率** (优先级排序):
1. 原生因果流式 (产品必须)
2. 单codebook + 低帧率12.5Hz (简单有效)
3. MoE (天工刚证明可行，新意高)

## T1 快速出活

### 4. VoiceAgent 落地
- 现有instruct能力接入agent (情感/副语言/方言)
- 加上: 打断恢复 + 隐式context推断
- 同步建对话级评测集

### 5. TTS Edit (数据引擎)
- 核心价值: **不是面向用户，而是数据飞轮**
- 音色编辑 → 扩充说话人多样性
- 情感编辑 → 扩充标注数据
- 内容编辑 → 标注纠错
- 与阶跃"生成式语音数据引擎"思路一致

## 资源分配

```
算力:  60% 架构训练(2B pretrain/CT) | 25% RL实验 | 15% 探索(Edit/播客)
数据:  P0 人类偏好对(RL必须) > P0 多维度标注 > P1 大规模低质量 > P2 对话数据
工具:  P0 IF-Reward评估器 > P0 强制对齐+韵律提取 > P1 偏好标注平台
```

**数据飞轮**: TTS Edit生成 → 标注 → 训练 → 更好的Edit → 更多数据

## 关键风险

| 风险 | 缓解 |
|------|------|
| IF-RM被抢发 | 速度优先，先用LLM-judge做proxy快速出结果 |
| Tokenizer选错 | 3个月内多路并行实验再定 |
| 算力不足 | 优先RL小实验(验证idea)，Scaling后做 |
| 2B训练不稳定 | 参考CosyVoice 3策略，用LLM权重初始化 |
